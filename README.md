# RISE FROM ASHES — TRTT Voyage Studio

A mobile-first personal writing studio created for TRTT Voyage.

## Files
- `index.html` — standalone responsive writing studio with live preview, Blogger HTML copy, and download.
- `blogger-drafts/rise-from-ashes.html` — first Blogger-ready personal reflection draft.

## Run
Open `index.html` in a modern browser. No build step, paid API, account token, or external JavaScript dependency is required.

## Publishing truth
The studio does not connect to Blogger or publish content. The included article is a draft only. Copy/download the HTML and review it in Blogger before manually saving or publishing. Never treat a local file as proof of a Blogger draft or live post.
